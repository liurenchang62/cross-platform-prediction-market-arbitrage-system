# trader 模块outline（按功能分类）

说明：路径相对于本目录 `trader/`。主程序入口为 `src/main.rs`；常量与路径定义集中在 `src/system_params.rs`。

--------------------------------------------------------------------------------
## 1. 主程序入口

| 文件 | 功能 |
|------|------|
| `src/main.rs` | Tokio 异步主循环：实盘 CONFIRM、`MonitorState` 与索引、全量匹配/价格追踪周期、套利校验与下单编排、与 `session_risk` / `desk_events` / `feishu_push` 等协作。 |

--------------------------------------------------------------------------------
## 2. 参数管理和分类映射

| 文件 | 功能 |
|------|------|
| `src/system_params.rs` | 全局常量（HTTP 重试、分页、匹配阈值、资金与单对上限、解析日窗等）；实盘下单安全锁 `CONFIRM` 后解锁；Kalshi/PM 环境变量名；`config/categories.toml` 路径；私钥加载与诊断辅助；日志路径常量（`DESK_EVENTS_JSONL`、`ARB_ROUNDS_STORE_PATH` 等）。 |
| `src/category_mapper.rs` | 从 `config/categories.toml` 加载类别与关键词；供匹配加权、PM 费用指数映射（`fee_model`）等使用。 |

--------------------------------------------------------------------------------
## 3. 市场统一与行情API接口

| 文件 | 功能 |
|------|------|
| `src/market.rs` | `Market`、`MarketPrices` 等：跨 Polymarket/Kalshi 的统一市场表示（标题、token、resolution、价格等）。 |
| `src/clients.rs` | `PolymarketClient`（Gamma/CLOB 等拉市场、订单簿）、`KalshiClient`（市场列表、订单簿等）；JSON 解析为 `Market`；resolution 日期与 Kalshi `expected_expiration_time` 等对表逻辑。 |

--------------------------------------------------------------------------------
## 4. 标题文本向量化、索引与匹配

| 文件 | 功能 |
|------|------|
| `src/text_vectorizer.rs` | TF-IDF 文本向量化（分词、词干、停用词、`MAX_VOCAB_SIZE` 等）。 |
| `src/vector_index.rs` | L2 归一化向量上的精确余弦检索（点积/矩阵批乘）；`IndexItem` 与索引构建。 |
| `src/category_vectorizer.rs` | 按类别维护 `TextVectorizer` + `VectorIndex`；`CategoryVectorizerManager`（含 unclassified 桶）。 |
| `src/market_matcher.rs` | 市场匹配器：类别内 TF-IDF + Top-K 余弦候选，结合 `validation` 二筛等，产出 PM↔Kalshi 候选对及置信度。 |
| `src/validation.rs` | 二筛：日期/体育/选举等规则与 regex，降低误匹配。 |
| `src/market_filter.rs` | 按 `RESOLUTION_HORIZON_DAYS` 过滤全量市场；追踪对结算日差与 horizon 修剪（与 `resolution_date` 口径一致）。 |

--------------------------------------------------------------------------------
## 5. 套利检测模块、滑点计算、成本利润估算

| 文件 | 功能 |
|------|------|
| `src/arbitrage_detector.rs` | `ArbitrageOpportunity` 与核心经济计算：订单簿阶梯、滑点、净利/ROI、严格校验主路径及辅助函数。 |
| `src/fee_model.rs` | Kalshi/PM taker 相关 USD 计算、`ArbCostParams`、Gas 与 surplus 缓冲（与 `system_params` 配合）。 |
| `src/kalshi_fee_schedule.rs` | 拉 `/series/fee_changes`，按 series 缓存 Kalshi taker 乘数 `KalshiFeeScheduleState`，供检测与下单一致使用、`fee_model::kalshi_series_from_ticker` 关联。 |

--------------------------------------------------------------------------------
## 6. 交易日志

| 文件 | 功能 |
|------|------|
| `src/tracking.rs` | `MonitorState`、`TrackedArbitrage`、`DeskCycleCtx`；追踪列表更新与修剪；`logs/arb_rounds_store.json` 读写（跨会话轮次上限）；腿向量化 id（`oriented_track_id`、`flip_binary_side`）。 |
| `src/tracking_log.rs` | 检出套利时终端仅打印 PM/Kalshi 订单簿 Top5（`print_arbitrage_detection_books`），不落盘 CSV。 |
| `src/desk_events.rs` | `logs/desk_events.jsonl`：一行一条 JSON 成交通知/摘要；线程安全追加。 |
| `src/trades_cache.rs` | `logs/trades_cache.txt`：实盘确认后清空并重写；`trade_out!` 宏输出同步镜像到该文件。 |

--------------------------------------------------------------------------------
## 7. 实盘执行与成交核对

| 文件 | 功能 |
|------|------|
| `src/kalshi_trade.rs` | Kalshi Trade API：RSA-PSS 签名、IOC 买/卖、余额/fills/positions、与 `require_live_orders_allowed` 联动。 |
| `src/polymarket_trade.rs` | Polymarket CLOB：官方 SDK 鉴权、FOK 等下单、collateral/conditional、fee-rate、成交与 micro 单位换算。 |
| `src/trade_reconciliation.rs` | 成交后核对：按订单拉 Kalshi fills 与 PM trades，终端汇总真实成交摘要。 |

--------------------------------------------------------------------------------
## 8. 飞书推送与预警

| 文件 | 功能 |
|------|------|
| `src/feishu_push.rs` | 飞书自定义机器人 `text` 推送；关键词 `【机器人】`；可选环境变量 `FEISHU_WEBHOOK`、`FEISHU_BOT_AUTHORIZATION`。 |
| `src/session_risk.rs` | 会话级风控：启动 T₀ 基线、两侧现金/抵押预警、暂停实盘、再平衡提示、飞书通知钩子；`SessionRiskHandle`。 |

--------------------------------------------------------------------------------
## 9. 独立文件，用于环境检查和赎回测试

| 文件 | 构建名 | 功能 |
|------|--------|------|
| `src/bin/check_env.rs` | `check_env` | 校验实盘相关环境变量与 Kalshi PEM 可读性；不打印密钥全文。 |
| `src/bin/pm_redeem.rs` | `pm_redeem` | 单独执行一轮 PM Proxy Relayer 赎回 + 刷新 CLOB Collateral（调用 `portfolio_monitor::pm_relayer_automation`）。 |

--------------------------------------------------------------------------------
