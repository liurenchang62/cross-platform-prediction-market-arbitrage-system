0. 安装 Rust 工具链（首次运行前） / Install Rust (first time only)
================================================================================

Rust 依赖由 Cargo 在首次编译时自动下载，无需手动安装依赖包。
只需确保系统中已安装 Rust stable 工具链：

Cargo auto-downloads all dependencies on first build. Only Rust itself needs
to be installed manually:

  # macOS / Linux
  curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

  # Windows — 从官网下载安装程序 / Download installer from:
  https://www.rust-lang.org/tools/install

安装后重启终端，验证：
Restart terminal after install, then verify:

  rustc --version
  cargo --version

安装完成后，cargo run 会自动拉取并编译所有依赖，无需其他操作。
After install, cargo run will fetch and compile all dependencies automatically.

1. 凭证与代理配置 / Credential & Proxy Setup
================================================================================

程序从 env/ 目录下 5 个文件自动加载凭证（无需手动 export）。
The program auto-loads credentials from 5 files under env/ (no manual export needed).

  env/env_params.env   — 加载开关 (LOAD_KEY_THROUGH_ENV)
  env/proxy.env        — HTTP 代理设置
  env/llm.env          — DeepSeek API Key + 飞书 Webhook（可选）
  env/kalshi.env       — Kalshi API Key ID + RSA 私钥文件路径
  env/polymarket.env   — Polymarket 私钥路径 + Relayer 凭证

加载优先级 / Loading priority:
  系统环境变量 > env/ 文件（文件不覆盖已设置的系统变量）
  System env vars > env/ files (files never overwrite already-set vars)

开关说明 / Switch:
  LOAD_KEY_THROUGH_ENV=true   从 env/ 文件加载（默认）
  LOAD_KEY_THROUGH_ENV=false  跳过文件，完全依赖系统环境变量（服务器/CI 模式）

代理说明 / Proxy:
  若使用 Clash / V2Ray / ClashVerge，默认端口为 7897。
  env/proxy.env 中已预填，直接使用或按需修改端口。
  服务器部署时注释掉 proxy.env 中的两行。

  推荐代理节点地区：日本 / 韩国 / 印尼（交易所对网络稳定性要求高）
  Recommended proxy regions: Japan / Korea / Indonesia

2. trader：主程序 / Main Live Trading Monitor
================================================================================

功能：Kalshi ↔ Polymarket 行情匹配 → 实时订单簿评估 → 执行套利 → 飞书推送
Feature: Market matching → live order-book economics → arb execution → Feishu alerts

  cargo run -p trader --release

启动时自动执行一次：Polymarket Relayer 赎回可结算头寸 + 刷新 CLOB Collateral
（需 POLYMARKET_SIGNATURE_TYPE=1 及完整 Relayer 凭证；后续周期内不再重复）

On startup, automatically runs once: PM Relayer redeem + CLOB Collateral refresh
(requires POLYMARKET_SIGNATURE_TYPE=1 + full Relayer credentials; not repeated in cycle)

进入实盘循环前需在终端输入 CONFIRM 确认（安全锁）。
A safety gate requires typing "CONFIRM" in the terminal before live orders are enabled.

3. trader：独立工具 / trader Standalone Tools
================================================================================

────────────────────────────────────────────────────────────────────────────────
3.1  环境自检 / Credential & Connectivity Check
────────────────────────────────────────────────────────────────────────────────

检查所有环境变量是否就绪、Kalshi / Polymarket API 是否可达。首次部署必跑。
Verifies all env vars are set and APIs are reachable. Run first on every new deployment.

  cargo run -p trader --bin check_env --release

────────────────────────────────────────────────────────────────────────────────
3.2  PM 独立赎回 / Standalone Polymarket Redeem
────────────────────────────────────────────────────────────────────────────────

经 Relayer 赎回可结算头寸并刷新 CLOB Collateral，不启动主监控循环。
Redeems settled PM positions via Relayer + refreshes CLOB Collateral, without starting monitor.

  # 仅赎回（默认）
  cargo run -p trader --bin pm_redeem --release

  # 赎回 + 批量 approve（allowance 不足时使用）
  cargo run -p trader --bin pm_redeem --release -- --approve-batch

4. portfolio-monitor：组合分析 / Portfolio Analytics
================================================================================

────────────────────────────────────────────────────────────────────────────────
4.1  统一组合快照 / Unified Portfolio Snapshot
────────────────────────────────────────────────────────────────────────────────

同时拉取 Kalshi + Polymarket 账户摘要，PM↔KS 对照表从 desk_events.jsonl 读取。
Pulls KS + PM account summary; PM↔KS mapping is read from desk_events.jsonl.

  cargo run -p portfolio-monitor --bin portfolio-snapshot --release

  # 指定 desk_events 路径
  cargo run -p portfolio-monitor --bin portfolio-snapshot --release -- --desk <path/to/events.jsonl>

────────────────────────────────────────────────────────────────────────────────
4.2  现金流 CSV 导出 / Cash Flow CSV Export
────────────────────────────────────────────────────────────────────────────────

按提示输入回望天数，生成时间升序的 cashflow.csv。
Enter lookback days when prompted; generates cashflow.csv in time-ascending order.

  cargo run -p portfolio-monitor --bin portfolio-cashflow --release

  # 指定输出目录（默认 portfolio_monitor/out）
  cargo run -p portfolio-monitor --bin portfolio-cashflow --release -- --out <输出目录>

────────────────────────────────────────────────────────────────────────────────
4.3  利润汇总 / P&L Summary
────────────────────────────────────────────────────────────────────────────────

终端打印全历史口径利润统计。
Prints full-history P&L summary to terminal.

  cargo run -p portfolio-monitor --bin portfolio-profit --release

────────────────────────────────────────────────────────────────────────────────
4.4  换手图表 / Trade Turnover Charts
────────────────────────────────────────────────────────────────────────────────

输出 PNG 图表：turnover_count.png（笔数）与 turnover_volume.png（名义金额）。
按提示输入回望天数；每次运行覆盖输出文件。
Outputs turnover_count.png and turnover_volume.png; overwrites previous output.

  cargo run -p portfolio-monitor --bin portfolio-turnover --release

  # 指定 desk_events 路径和输出目录
  cargo run -p portfolio-monitor --bin portfolio-turnover --release -- --events <jsonl> --out <目录>

────────────────────────────────────────────────────────────────────────────────
4.5  套利三时点回报对比 / Arb 3-Point Reconciliation
────────────────────────────────────────────────────────────────────────────────

对比识别时 → 执行后 → 结算后的回报差异。
Compares returns at: detection time → post-execution → post-settlement.

  # 仅显示执行数据（不查 API）
  cargo run -p portfolio-monitor --bin arb-reconcile --release

  # 同时从 Kalshi + PM API 查询真实结算收益
  cargo run -p portfolio-monitor --bin arb-reconcile --release -- --settled

  # 指定 desk_events 路径
  cargo run -p portfolio-monitor --bin arb-reconcile --release -- --desk <jsonl> --settled

────────────────────────────────────────────────────────────────────────────────
4.6  当前持仓订单簿 / Live Order-Book for Open Positions
────────────────────────────────────────────────────────────────────────────────

显示每个未平仓对的 Kalshi + PM 双边订单簿（各取前 5 档）。
Shows KS + PM order-book (top-5 bid/ask) for each open position pair.

  cargo run -p portfolio-monitor --bin portfolio-position-markets --release

  cargo run -p portfolio-monitor --bin portfolio-position-markets --release -- --desk <jsonl>

5. portfolio-monitor：一次性操作工具 / One-Off Operation Tools
================================================================================

────────────────────────────────────────────────────────────────────────────────
5.1  USDC.e → pUSD 自动转换 / Wrap USDC.e to pUSD  [Polymarket V2 必需]
────────────────────────────────────────────────────────────────────────────────

Polymarket 于 2026-04-28 将 CLOB 保证金由 USDC.e 迁移至 pUSD。
若代理钱包中仍有 USDC.e，运行此工具通过 CollateralOnramp 合约自动转换。
首次部署或账户中有 USDC.e 时需运行一次。

Polymarket migrated CLOB collateral from USDC.e → pUSD on 2026-04-28.
Run once if your proxy wallet still holds USDC.e; converts via CollateralOnramp.

  cargo run -p portfolio-monitor --bin pm-wrap-collateral --release

  需要 / Requires:
    POLYMARKET_SIGNATURE_TYPE=1
    POLYMARKET_PRIVATE_KEY 或 POLYMARKET_PRIVATE_KEY_PATH
    POLYGON_RPC_URL（可选，不填使用公共 RPC）

────────────────────────────────────────────────────────────────────────────────
5.2  PM 赎回诊断 / Polymarket Redeem Diagnostics
────────────────────────────────────────────────────────────────────────────────

查询链上 payout 余额，不提交任何 Relayer 交易。纯读取，适合排查赎回问题。
Queries on-chain payout balances without submitting any Relayer transactions.

  cargo run -p portfolio-monitor --bin portfolio-pm-redeem-diagnose --release

────────────────────────────────────────────────────────────────────────────────
5.3  定向平仓 / Directed Position Close
────────────────────────────────────────────────────────────────────────────────

给定 Kalshi ticker，从 desk_events 找对应 PM token，两腿同时平仓。
默认 dry-run（只打印订单簿和仓位），加 --execute 才实际下单。

Given a Kalshi ticker, finds the matching PM token and closes both legs.
Default is dry-run (prints only); add --execute to submit real orders.

  # Dry-run（查看仓位和当前订单簿，不下单）
  cargo run -p portfolio-monitor --bin close-position --release -- \
      --ks-ticker KXNETFLIXRANKSHOW-26APR20-BIG

  # 实际执行平仓（⚠ 会下单）
  cargo run -p portfolio-monitor --bin close-position --release -- \
      --ks-ticker KXNETFLIXRANKSHOW-26APR20-BIG --execute

  # 指定 desk_events 路径
  cargo run -p portfolio-monitor --bin close-position --release -- \
      --ks-ticker <ticker> --desk <jsonl> --execute

6. 环境变量速查表 / Environment Variable Reference
================================================================================

以下变量通常通过 env/ 文件注入，也可手动 export（系统变量优先）。
Usually injected via env/ files; can also be exported manually (system vars take priority).

────────────────────────────────────────────────────────────────────────────────
通用 / General
────────────────────────────────────────────────────────────────────────────────

  LOAD_KEY_THROUGH_ENV        true（默认）从 env/ 文件加载；false 完全依赖系统变量
  HTTP_PROXY / HTTPS_PROXY    HTTP 代理地址，如 http://127.0.0.1:7897

────────────────────────────────────────────────────────────────────────────────
Kalshi
────────────────────────────────────────────────────────────────────────────────

  KALSHI_API_KEY_ID            API Key UUID（Kalshi Settings → API Keys）
  KALSHI_PRIVATE_KEY_PATH      RSA PEM 私钥文件的绝对路径
  KALSHI_ORDERBOOK_DEBUG       1 = 每周期打印订单簿调试信息（可选）

────────────────────────────────────────────────────────────────────────────────
Polymarket
────────────────────────────────────────────────────────────────────────────────

  POLYMARKET_SIGNATURE_TYPE    签名类型：0=EOA, 1=Proxy（推荐）, 2=GnosisSafe
  POLYMARKET_PRIVATE_KEY       EVM 私钥 hex（可带 0x），与 PATH 二选一
  POLYMARKET_PRIVATE_KEY_PATH  EVM 私钥文件绝对路径（优先于 PRIVATE_KEY）
  POLYMARKET_API_KEY           CLOB API Key
  POLYMARKET_ADDRESS           代理钱包地址（0x...）
  POLYGON_RPC_URL              Polygon RPC（可选，默认使用公共 RPC）
  POLYMARKET_RELAYER_URL       Relayer 地址（可选，默认 relayer-v2.polymarket.com）

────────────────────────────────────────────────────────────────────────────────
Relayer（与 Polymarket 凭证相同，通常填同一套值）
────────────────────────────────────────────────────────────────────────────────

  RELAYER_API_KEY              同 POLYMARKET_API_KEY
  RELAYER_API_KEY_ADDRESS      同 POLYMARKET_ADDRESS

────────────────────────────────────────────────────────────────────────────────
LLM 验证 / LLM Validation
────────────────────────────────────────────────────────────────────────────────

  LLM_PROVIDER                 deepseek（目前支持）
  DEEPSEEK_API_KEY             DeepSeek API Key
  LLM_MODEL                    deepseek-chat（默认）或 deepseek-reasoner
  LLM_TIMEOUT_MS               超时毫秒（默认 10000）
  LLM_MAX_TOKENS               最大响应 token 数（默认 400）
  LLM_TEMPERATURE              创造性参数（默认 0.0 最保守）

────────────────────────────────────────────────────────────────────────────────
飞书推送 / Feishu Notifications
────────────────────────────────────────────────────────────────────────────────

  FEISHU_WEBHOOK               自定义飞书 Webhook URL（不设则使用源码内置默认值）
  FEISHU_BOT_AUTHORIZATION     自定义机器人鉴权 token（不设则使用源码内置默认值）
